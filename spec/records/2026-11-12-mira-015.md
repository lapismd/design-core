The first-party dependency PR raised `@lapismd/mira` from `~0.1.4` to `~0.1.5`.
That range no longer admits 0.1.4, so the Code Editor npm-resolution unit failed
one assertion while the rest of CI passed.

rejects 0.2.0 plus sibling/`codemirror` sources. The 0.1.4 math-repair history
and zero-finding packed-audit policy are unchanged.
