# Tasks Filters and Menus

Exclusive page filters use the installed `ToggleGroup`; compact filter controls
use a labelled `DropdownMenu` or `Popover`. Menus group related actions,
separate destructive actions, and restore focus to their trigger.

Use the existing `Command` + `Dialog` pairing for command/search experiences.
Do not build custom focus traps, portals, or menu keyboard handling.
