# Task Properties

An ordered property rail for due date, assignee, priority, labels, and list
membership. Every row has a text label, visible current value, and a menu or
popover trigger. Empty values say what will be added rather than showing a bare
icon.

## Reuse now

- `TaskDueCalendar` from `@stevejuma/ui/forms` for the initial due-date picker.
- `Popover`, `Select`, `DropdownMenu`, `Badge`, `Button`, and `Field`.

## Add when required

- `Checkbox` for multi-select menus.
- `Command` is already installed for searchable assignee/label selection.
