# TaskProperties

An ordered property rail for due date, assignee, priority, labels, and list
membership. Every row keeps a text label and its current value visible, and
opens a popover/select/menu to change it. Implementation status: **Done** for
the leaf-control surface.

Due date uses the shared `TaskDueCalendar` from `@stevejuma/ui/forms`. Because
the `TaskReference` contract models `due` as a relative bucket
(`overdue`/`today`/`tomorrow`/`later`/none) rather than a calendar date, the
picked calendar day is converted to the nearest bucket relative to today when
it is committed.
