# TasksFeedback

Renders one of the five `TasksFeedbackState` kinds — `empty`, `loading`,
`preserving-error`, `status`, and `undo` — with the installed `Empty`,
`Skeleton`, `Spinner`, and `Alert` primitives. Loading rows retain task-row
geometry, and a recoverable error keeps the last usable result visible while
offering retry. Implementation status: **Done** for the leaf-control surface.
