# Layout and navigation guidance

Use `@stevejuma/ui/apps/beancount` layout and navigation components before
recreating application chrome. Their Stories are the visual contract; Docs
pages supply props and interactive examples.

## Application frame

Use [App Shell](?path=/docs/apps-beancount-layout-app-shell--docs) once per
application view. Give it the page title, place persistent navigation in its
`sidebar` slot, and put page-specific content only in the main content slot.
Use `height="container"` for a bounded embedded preview; applications use the
viewport default.

Do not build a second shell around a page or make route content responsible for
the sidebar gutter, header, or workspace border.

## Page bodies

Use [Content Scroll Area](?path=/docs/apps-beancount-layout-content-scroll-area--docs)
when a page body must scroll independently within the shell. It keeps the shared
viewport styling and keyboard access. The page still owns its content padding
through `contentClass`.

For a user-resizable desktop rail, use
[Resizable Sidebar](?path=/docs/apps-beancount-layout-resizable-sidebar--docs).
Keep its `width` controlled and persist that value in the application if needed.

## Navigation

- Use [Sidebar Navigation](?path=/docs/apps-beancount-navigation-sidebar-navigation--docs)
  for the visual navigation list. Keep routing outside it: pass controlled
  `activeHref` state and update it from `onNavigate`.
- Use [Workspace Tree Navigation](?path=/docs/apps-beancount-navigation-workspace-tree-navigation--docs)
  for a controlled nested file, folder, tag, or page tree.
- Use [Ledger Workspace Navigation](?path=/docs/apps-beancount-navigation-ledger-workspace-navigation--docs)
  when those trees form a multi-ledger sidebar.
- Use [Saved Query History](?path=/docs/apps-beancount-navigation-saved-query-history--docs)
  for expandable query history with copy/delete actions.
- Use [Cycle Select](?path=/docs/apps-beancount-navigation-cycle-select--docs)
  only for a small ordered set that benefits from previous/next actions. For
  ordinary searchable choices, use forms `FilterCommandPicker` instead.
- Use [Page Pagination](?path=/docs/apps-beancount-navigation-page-pagination--docs)
  for paged collections.

## Verify the composition

Every interactive navigation story keeps state locally and asserts a visible
result. New layouts must cover bounded shell behaviour, keyboard reachability
for scrolling regions, and catalogue themes before application migration.
