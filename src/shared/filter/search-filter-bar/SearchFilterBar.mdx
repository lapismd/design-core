# SearchFilterBar

Search chrome with optional filter chips/snippets. Opt into
`inputMode="filter-query"` for structured syntax highlighting and host-supplied
field / operator / value autocomplete. Completed predicates such as
`amount = 23` render as removable inline chips with syntax-colored
labels once the value is set and the caret leaves the term; click a chip to
edit field / operator / value (`valueKind` or host `ValueEditor`). Free text,
tags, and incomplete typing stay plain.

Import from `@stevejuma/ui/filter`. See [Filter/Guidance](?path=/docs/filter-guidance--docs)
for the query language.

## Guidance

### When to use

- Workspace sidebars and list filters
- Domain filter languages with field completions
- Search + chip filters with a clear control

### When not to use

- Schema field rows — use forms `FormField` / StructuredForm around this bar
- Generic option picking alone — use forms `FilterCommandPicker`

## Usage

<Source
  language="ts"
  code={`import { SearchFilterBar, type SearchFilterSyntax } from "@stevejuma/ui/filter";

<SearchFilterBar
  value={query}
  inputMode="filter-query"
  filterSyntax={syntax}
  onValueChange={(next) => (query = next)}
/>
`} />
