# `@stevejuma/ui`

Shared Storybook catalog for shadcn primitives, structured forms, and
app-specific components used by CV Studio and beancount-js-studio.

Agent conventions: run `pnpm ui guide` from the package root (JSON:
`pnpm ui guide <topic> --json`). Decision pages: **Shadcn/Guidance**,
**UI Forms/Guidance**.

## Layers

1. **Shadcn** — generic primitives under `src/shared/shadcn`
2. **Forms** — config-driven form engine and field controls under `src/shared/forms`
3. **App folders** — `src/apps/cv` and `src/apps/beancount` for domain UI

Import shared primitives from `@stevejuma/ui/shadcn/<family>` and forms from
`@stevejuma/ui/forms`.
