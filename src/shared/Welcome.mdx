# `@stevejuma/ui`

Shared Storybook catalog for shadcn primitives, structured forms, filter
controls, AI presentation, structural shells, and workspace surfaces.

Agent conventions: run `pnpm ui guide` from the package root (JSON:
`pnpm ui guide <topic> --json`). Decision pages: **Shadcn/Guidance**,
**UI Forms/Guidance**.

## Layers

1. **Shadcn** — generic primitives under `src/shared/shadcn`
2. **Forms** — config-driven form engine and field controls under `src/shared/forms`
3. **Filter** — search chrome and filter-query language under `src/shared/filter`
4. **AI** — reusable assistant presentation under `src/shared/ai`
5. **Shell** — bounded app chrome, fixed regions, section Scroll Areas, and independently collapsible/closeable/resizable sidebar state under `src/shared/shell`
6. **Workspace** — tabs, splits, views, and application framework under `src/shared/workspace`

Import shared primitives from `@stevejuma/ui/shadcn/<family>`, forms from
`@stevejuma/ui/forms`, search/filter from `@stevejuma/ui/filter`, and AI
presentation from `@stevejuma/ui/ai`. Use `@stevejuma/ui/shell` for structural
application chrome and `@stevejuma/ui/workspace` for the full workspace
framework.
