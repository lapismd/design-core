# WorkspaceDropOverlay

Visualizes the registered tab-body drop target. Edge regions use the Lapis
proportions: 25% left/right/top and 35% bottom; the remaining area is centre.

## Usage

<Source
  language="html"
  code={
    "<WorkspaceTabsDrop {controller} {drag} parent={tabs}>{content}</WorkspaceTabsDrop>"
  }
/>
