# WorkspaceSidebar

`WorkspaceSidebar` composes the reusable icon tab bar, grouped panels, regular
view bodies, empty container, drop targets, and close control for either side.
Right-clicking a group icon opens the source group menu, including shadcn-backed
name/icon editing, visible-panel management, ungrouping, and close actions.
Each top-level icon or group is also a before/after insertion anchor. Dropping
beside a group creates a normal sidebar tab, while dropping within its body
continues to use the grouped-panel top/bottom behavior.

An ungrouped registered view inherits the sidebar panel surface through the
Workspace view tokens. A grouped view resets those tokens to the normal
workspace surface while the group header retains sidebar chrome.
