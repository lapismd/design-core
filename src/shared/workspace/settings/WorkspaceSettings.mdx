# Workspace settings

The settings family renders controller-owned configuration schemas using native
CSS and public Workspace tokens. It does not depend on Tailwind or shadcn
presentation primitives.

Applications can use the complete `WorkspaceSettingsSurface`, render
`AppShell.Settings` inside `AppShell.Root`, or assemble the compound parts:

```svelte
<AppSettings.Root controller={app.settings} {app}>
  <AppSettings.Search />
  <AppSettings.Navigation />
  <AppSettings.Content />
</AppSettings.Root>
```

## Controller-owned settings

The built-in application controller contributes Appearance, Workspace,
Hotkeys, and Core Plugins. Updating a rendered field writes through
`WorkspaceSettingsController`, emits a typed change event, and requests a
debounced save through the configured persistence adapter.
