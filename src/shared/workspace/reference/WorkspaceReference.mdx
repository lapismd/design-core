# Canonical Lapis Reference

This review-only story assembles the shell through the public Workspace API and
connects it to the immutable Lapis light and dark captures.

<Canvas of={Stories.Shell} />

## Image ownership

- Candidate images are generated by the target repository's guarded Visual
  Delta workflow at 1280 × 900 with device scale factor 3.
- Canonical images were captured from pinned Lapis revision
  `a371198e495d9e4e465c2960a04b3a4fd11f4023` at 1440 × 960 with device scale
  factor 1.
- Normal tests compare candidates and never rewrite the canonical images.
- The candidate remains `visual-pending` until manual review.

## Theme review

The default candidate is light. Select the Visual Delta **Dark** mode to apply
the global `colorMode: dark` value and inspect the corresponding dark candidate
and canonical image.
