# WorkspaceEmpty

Workspace empty content for leaves with no resource and for serialized views
whose registration is unavailable. It composes design-core's shadcn `Empty`
and `Button` primitives over the workspace panel surface.

## Usage

<Source language="ts" code={Basic} />

<Primary />

The application controller exposes `emptyViewActions` as a public ordered
registry. Downstream services can add and remove actions without replacing the
component:

```ts
const removeAction = app.emptyViewActions.addItem({
  id: "consumer:create-note",
  label: "Create Note",
  onSelect: () => createNote(),
});
```

## Style

Colocated CSS: `WorkspaceEmpty.css`. Paint reads the public
`--ui-workspace-*` token layer. The root uses `--ui-workspace-panel` so its
surface follows the registered sidebars, while shadcn owns empty-state and
button paint.
