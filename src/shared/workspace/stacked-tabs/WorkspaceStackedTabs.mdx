# WorkspaceStackedTabs

`WorkspaceStackedTabs` renders the Lapis stacked-pane geometry while retaining
the target repository's native CSS and public Workspace tokens.

## Contract

- The supplied pane must be a live `WorkspaceTabsNode` owned by the controller.
- Tab activation, closing, presentation changes, and drops use the controller.
- The horizontal viewport scrolls without exposing a browser scrollbar.
- Icon menu, title, and close actions are valid sibling controls. The title is
  the drag and focus-mode surface; the icon opens the complete pane menu and
  activates the tab first.
- Headers register the same before/after insertion targets and shared marker
  as top tabs, including corrected same-pane movement in both directions.
- Main-workspace chrome exposes the same maximize/restore toggle beside tab
  options. Its pressed state uses workspace primary paint, replacing the
  separate focus-mode close control.
- A second double-click while the pane is focused restores the normal shell;
  the focused title also supports the `Delete` key.
