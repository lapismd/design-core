# WorkspaceViewHost

Connects a serialized tab to the controller-owned view registry. Applications
register view factories once; leaves retain only JSON-safe type and state.

## Style

Colocated CSS: `WorkspaceViewHost.css`. The host supplies full-size clipping
and paints every registered Svelte or imperative view with
`--ui-workspace-view-background` / `--ui-workspace-view-foreground` resolved by
the destination surface. View content should remain transparent unless it
intentionally overrides those tokens for a specialized surface.
