# Mobile Shell

The mobile renderer presents the same serializable workspace as a full-height
single-page editor, revealable sidebars, and an open-tab overview.

## Settings

- `defaultPage` chooses the editor or tab overview on mount.
- `showBottomNav` controls the floating dock.
- `includeSidebarsInTabs` includes sidebar leaves in the overview.
- `includeFloatingInTabs` includes floating and popout leaves.

`AppShell.Surface` reads these values from `AppShellController.mobile` unless a
surface prop explicitly overrides them.

`AppShell.Surface.mobileSearchAction` and `mobileCreateAction` accept public
`WorkspaceAction` descriptors. The consumer owns file/search policy; the shell
uses their labels, availability and callbacks. Without these descriptors the
dock browses the left sidebar and creates workspace tabs.

`controller.renderer.mobileNavigation` owns transient page, sidebar and menu
state, so commands can open editor, tabs, menus and either sidebar. Its state is
never serialized into the desktop layout. The App Shell surface connects its
mobile action sheet to the existing command palette.

## Behavior

Tab activation, close, undo close, creation, and sidebar selection use the same
controller mutation and persistence path as desktop rendering.

The editor stage supports Lapis-shaped horizontal pan gestures with a movement
threshold, vertical-axis cancellation, velocity settling, and nearest-page
snapping. The view actions and open-tabs controls use shell-scoped bottom action
sheets, so the presentation remains inside the active `AppShell.Root`.

## Composable pieces

Applications may use the complete `WorkspaceMobile` renderer or compose its
public pieces:

- `WorkspaceMobileActionSheet` provides the accessible native-CSS bottom sheet.
- `WorkspaceMobileActionsDrawer` renders quick and pane-menu actions.
- `WorkspaceMobileViewActions` renders up to two view actions and the drawer
  trigger.
- `WorkspaceMobileDock` renders the floating editor navigation.
- `WorkspaceMobileTabs`, `WorkspaceMobileTabTile`, and
  `WorkspaceMobileTabsActions` compose the open-tab overview.
- `WorkspaceMobileSidebar` renders a selectable sidebar surface.

Every piece receives public controller, tab, or sidebar handles; none requires a
global application value or private drag state.

Sidebar selectors compose the shared shadcn Select with keyboard selection and
focus return. Descendant note scroll events hide chrome while scrolling down
and reveal it while scrolling up or returning to the top.
