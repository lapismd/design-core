# WorkspaceSidebarGroup

`WorkspaceSidebarGroup` renders one grouped sidebar item as a measured vertical
panel stack. Its collapsed size is always the source 32px header converted into
the measured stack percentage.

The full panel header owns activation, collapse and drag behavior. Its context
menu can hide the panel, move it back to normal sidebar tabs, close it, and
include the registered view's pane actions. Registered drop targets expose only
top and bottom insertion positions.
