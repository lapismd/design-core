# Workspace Problems

`WorkspaceProblems` renders plain, ephemeral diagnostics supplied through the
application-owned `AppShellController.diagnostics` manager. The package never
interprets resource URIs or imports a filesystem, editor, language service, or
Lapis API.

Import the model, panel, and optional presentation plugin from
`@lapismd/design-core/workspace/problems`.

## Model and ownership

- Positions are zero-based and ranges are end-exclusive.
- Severities are `error`, `warning`, `information`, and `hint`.
- A resource is an opaque URI plus optional label, detail, and icon hints.
- A `null` resource publishes a workspace-wide issue.
- Collections replace diagnostics per resource and are isolated by owner.
- Plugins created through `AppShellPlugin.createDiagnosticCollection()` dispose
  their collections automatically during teardown.
- Diagnostics are never persisted. Workspace layout remains the only persisted
  state, including a moved Problems leaf.

## Presentation plugin

`problemsPlugin()` registers the movable view and the `App Shell: Show Problems`
command. After layout hydration it preserves an existing leaf or seeds one
inactive, closable tab in the closed bottom dock. New problems never open the
dock automatically; the command reveals the existing destination or recreates
the tab after closure.

## Tree and table views

The panel starts with the grouped tree presentation. Its upper-right view action
switches to a compact table with **Code**, **Message**, **File**, and **Source**
columns, and switches back without changing workspace layout. Both views use the
same severity filters, search, navigation, related information, and context
actions. Table overflow is governed by the shared shadcn Scroll Area in both
axes, including when the view is moved into a narrow sidebar. A host that
prefers the flat presentation may pass
`defaultViewMode: "table"` to `problemsPlugin()`; the mode remains transient and
diagnostics remain ephemeral.

## Consumer adapters

Primary activation calls the host navigation adapter with the opaque resource
and optional range. Related-information rows use the same adapter. Built-in
context actions copy the message or formatted problem; each collection may
synchronously append actions such as quick fixes while their callbacks remain
free to run asynchronously.
