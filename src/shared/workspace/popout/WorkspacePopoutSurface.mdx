# Popout Surface

`AppShell.Root` installs an injectable popout host and mounts each runtime
popout tree into the returned document. Applications can pass `null` to disable
browser popouts or provide a desktop/native adapter implementing the same
public host contract.

The detached surface reuses the controller, view registry, drag state, tabs,
splits, and theme tokens rather than creating a second application singleton.
It also establishes an inline-overlay boundary. Trigger-based shadcn overlays
therefore render only in the popout document; outside a popout those same
families follow the trigger document's body automatically.
