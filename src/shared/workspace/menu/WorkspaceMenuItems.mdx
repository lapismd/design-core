# Workspace menu

`WorkspaceMenuItems` renders the serializable, fluent `WorkspaceMenu` model
without coupling applications to a shadcn wrapper. Items, separators, checked
state, disabled state, and nested menus use direct Bits UI behavior and public
Workspace tokens.
