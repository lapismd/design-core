# WorkspaceTabs

Controller-backed top tabs adapted from the Lapis workspace renderer. Header
and content containers remain direct children of the raw Bits UI root.

## Behaviour

- Selecting, adding, and closing tabs mutates the controller and schedules a
  layout save.
- Five or more tabs preserve a usable minimum size and overflow horizontally
  with no visible scrollbar.
- The close action never shrinks; the title and decorative icon yield in
  constrained split panes.
- Pointer and HTML5 movement share the registered insertion and body-drop
  targets.
- Main-workspace panes expose a maximize toggle beside the tab-options menu.
  The pressed primary state restores the pane without a separate focus-mode
  close control.
- Add, maximize, and options controls keep compact fixed hit areas and reserve
  their combined width before tab titles shrink or scroll.
- Double-clicking the title trigger enters focus mode; double-clicking any tab
  in the focused pane restores the normal shell.
- Right-clicking a tab or activating its icon button opens the complete
  controller-owned pane menu. Icon activation selects the tab first, while a
  context click leaves selection unchanged.

## Style

Colocated CSS: `WorkspaceTabs.css`. Tab geometry uses public
`--ui-workspace-tab-*` tokens, including dedicated action-hover foreground and
background values for icon and close controls inside an already-hovered tab,
and retains the source active-tab curves.
