# Workspace view header

The view header consumes `WorkspaceViewDefinition.getChrome()` and the shared
pane-menu builder. Applications contribute serializable breadcrumbs, history
callbacks, header actions, and menu items without owning shell markup.

For file views, contribute parent-path segments through
`WorkspaceViewChrome.breadcrumbs` (filename stays in `title`). History uses
`canGoBack` / `canGoForward` with `onGoBack` / `onGoForward`.

Breadcrumbs stay start-aligned beside the nav when space allows. When space is
tight, the path shrinks and clips from the left first so segments nearest the
filename — and the final title — stay readable as long as possible.

Set `titleEditable` and `onTitleCommit` to enable click-to-edit rename on the
header title. Editing stays in place with the same typography — breadcrumbs
remain visible while the title is being renamed. Enter or blur commits; Escape
cancels.
