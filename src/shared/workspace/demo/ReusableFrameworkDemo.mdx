# Reusable Framework Demo

This Lapis-like application uses only the public Workspace framework. A static
plugin contributes views, commands, palette results, settings, ribbon items,
and status items. F-Mode and Notifications are installed through their public
optional descriptors.

The controller restores and saves a JSON-safe layout through an asynchronous
adapter. Tabs, splits, sidebars, grouped panels, floating windows, mobile
composition, application metadata, and active identity all remain owned by
that controller.

The left-sidebar footer opens the controller-owned settings dialog. Its
Appearance, Workspace, Hotkeys, and Core Plugins sections are registered by the
same application controller used by the visible shell.
