# WorkspaceIcon

Renders a serializable Lucide icon name and supports application-owned icons
through `registerWorkspaceIcon`. Unknown names use the stable `file` fallback.
`WorkspaceIconPicker` is the searchable popover used by Settings
`presentation: "icon"`.

## Style

Colocated CSS: `WorkspaceIcon.css`. The icon inherits size and colour from its
host, which keeps it usable inside tabs, buttons, menus, ribbon items, and
status items without utility-class coupling.
