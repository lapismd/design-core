# Command View

Host-agnostic searchable command surface with composable input and item parts.
Drop the view into a dialog, popover, or inline pane. Command View does not
export overlay chrome.

This is a project-authored native-CSS family. It composes bits-ui Command for
keyboard highlight and `shouldFilter`, and uses the public ScrollArea viewport
for overflowing lists.
