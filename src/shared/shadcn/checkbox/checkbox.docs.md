# Checkbox

A control that allows the user to toggle between checked and not checked.

## Installation

```bash
pnpm ui:add checkbox
```

## Usage

```html
<script lang="ts">
  import { Checkbox } from "@lapismd/design-core/shadcn/checkbox";
</script>
```

```html
<Checkbox />
```
