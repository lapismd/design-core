# Breadcrumb

Displays the path to the current resource using a hierarchy of links.

Adapted from the upstream [shadcn-svelte docs](https://github.com/huntabyte/shadcn-svelte/blob/bf4f461d88526359d0e96e1950f637912bbeebe7/docs/content/components/breadcrumb.md).
