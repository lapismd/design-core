## Installation

```bash
pnpm ui:add alert
```

## Usage

```html
<script lang="ts">
  import * as Alert from "@stevejuma/ui/shadcn/alert";
</script>
```

```html
<Alert.Root>
  <Alert.Title>Heads up!</Alert.Title>
  <Alert.Description>
    You can add components to your app using the cli.
  </Alert.Description>
</Alert.Root>
```
