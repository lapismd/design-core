# Column Canvas

Horizontal, selection-driven column cascade for Miller-column / Finder-style
navigation. A typed app-owned controller owns path selection, widths, and
collapse/close. Compound parts (`Header`, `Toggle`, `Close`, `Body`, `Item`)
provide consistent chrome so hosts do not invent row or header styling.

This is a project-authored native-CSS family. It is not the same as
[Resizable](?path=/docs/shadcn-layout-resizable--docs): Resizable fills a box
with percentage pane groups, while Column Canvas grows a horizontally scrolling
canvas of fixed-width columns.

## Usage

Always mount `Column` parts under `Root`. Configure each column’s `pathLevel`
so cascade visibility is controller-owned (same idea as AppShell self-gating
closed/collapsed chrome). Hosts map `path` keys to domain rows; they do not
`{#if}` columns into the tree. The primary demo uses three columns with
collapse, resize, and a closeable details pane. Use **Show code** on the
preview for a copy-pasteable example.

## Examples

### All features

Categories → components → details. Every column is collapsible and resizable;
details is also closeable. Selecting a component reopens details (`openOnSelect`)
and fills it with Name / Id / Role / Import / Category values from that row.

<Canvas of={ColumnCanvasStories.AllFeatures} meta={ColumnCanvasStories} />

### Three-level cascade

Path selection only — categories → components → detail prose, with
toggle-select clearing deeper levels (deeper columns hide via `pathLevel`).

<Canvas of={ColumnCanvasStories.ThreeLevelCascade} meta={ColumnCanvasStories} />

### Closeable columns

`Close` removes a closeable column from the canvas; `controller.open(id)` or
selecting a row restores it when `openOnSelect` is enabled.

### Collapse and expand

`Toggle` collapses a column to a vertical rail; expand restores it.

## Parts

- `Root` — installs the controller, horizontal scroller, trailing spacer
- `Column` — controller-driven width/collapse; optional convenience `title`/`count`
- `Header` / `Title` / `Count` / `HeaderActions` / `Toggle` / `Close`
- `Body` / `Item`
- `createColumnCanvasController` — typed path + layout controller
- `CollapsedColumn` — low-level rail escape hatch (prefer controller collapse)

## Styling

Override `--ui-column-canvas-*` tokens on an ancestor. Production sources use
native CSS and compose the shared Button for Toggle and Close.
