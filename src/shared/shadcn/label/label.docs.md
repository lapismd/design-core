# Label

Renders an accessible label associated with controls.

## Installation

```bash
pnpm ui:add label
```

## Usage

```html
<script lang="ts">
  import { Label } from "@stevejuma/ui/shadcn/label";
</script>
```

```html
<label for="email">Your email address</label>
```
