# Progress

Displays an indicator showing the completion progress of a task, typically displayed as a progress bar.

## Installation

```bash
pnpm ui:add progress
```

## Usage

```html
<script lang="ts">
  import { Progress } from "@lapismd/design-core/shadcn/progress";
</script>
```

```html
<progress value="{33}" />
```
