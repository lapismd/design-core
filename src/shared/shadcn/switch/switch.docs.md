# Switch

A control that allows the user to toggle between checked and not checked.

## Installation

```bash
pnpm ui:add switch
```

## Usage

```html
<script lang="ts">
  import { Switch } from "@lapismd/design-core/shadcn/switch";
</script>
```

```html
<Switch />
```
