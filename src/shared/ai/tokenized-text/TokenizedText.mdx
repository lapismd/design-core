# Tokenized Text

Renders a text string with token patterns replaced by inline Badge
components. Wrap any message body inside ChatMessageBubble to turn raw
@mentions, #tags, or /commands into styled badges. When no tokens match
or none are provided, the text renders as-is: so you can use
ChatTokenizedText unconditionally on every message.

Adapted from
[Astryx ChatTokenizedText](https://astryx.atmeta.com/components/ChatTokenizedText).
