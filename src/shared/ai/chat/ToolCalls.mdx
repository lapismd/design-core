# Tool Calls

ChatToolCalls displays tool or function call invocations from an LLM
response. Pass an array of calls and the component handles the rest: a
single call renders inline, while multiple calls collapse into a summary
with the latest call visible at the surface. Use it anywhere an AI agent
shows what actions it took.

Adapted from
[Astryx ChatToolCalls](https://astryx.atmeta.com/components/ChatToolCalls).
