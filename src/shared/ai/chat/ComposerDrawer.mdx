# Composer Drawer

Collapsible drawer panel that sits above the chat input inside
ChatComposer. Pass it to the composer's drawer slot to show attachments,
context chips, or any supplementary content. When count is provided the
drawer gains a collapse toggle: collapsed state shows a badge and label,
expanded state shows all children.

Adapted from
[Astryx ChatComposerDrawer](https://astryx.atmeta.com/components/ChatComposerDrawer).

## Examples

Common configurations, variations, and states.

### Attachments

Drawer with two rows: a scrollable carousel of image thumbnails and a
row of removable file tokens. Omit count to keep the drawer always
expanded.

### Collapsible

Drawer with many items and a collapse toggle. Pass count to enable the
toggle; collapsed state shows a badge with the total count and a label.

<Canvas of={ComposerDrawerStories.Collapsible} meta={ComposerDrawerStories} />

### Feedback

options. Use for user confirmation workflows that require explicit
action before proceeding.
