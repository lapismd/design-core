# Layout

ChatLayout is the layout shell for full-page chat interfaces. It renders
messages in normal page flow and docks the composer to the bottom with a
frosted glass blur layer. Density adapts automatically via container
width observation. Use it to wrap ChatMessageList and ChatComposer for a
complete chat experience with built-in auto-scroll and a
scroll-to-bottom button.

Adapted from
[Astryx ChatLayout](https://astryx.atmeta.com/components/ChatLayout).
