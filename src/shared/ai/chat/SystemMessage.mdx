# System Message

Centered system message for non-sender content like date separators,
membership changes, and status notices. It is not a chat bubble; it has
no avatar, no alignment, and no sender context. Use the divider variant
for temporal breaks and default for inline status updates.

Adapted from
[Astryx ChatSystemMessage](https://astryx.atmeta.com/components/ChatSystemMessage).
