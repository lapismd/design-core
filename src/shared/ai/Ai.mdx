# AI

Shared presentational AI chat components in `@stevejuma/ui/ai`.

They sit on top of the shared shadcn primitives and are **prop-driven** — no
application store, networking, persistence, routing, or model SDK.

```ts
import { AiChatPanel, Chat, ExperimentalChat } from "@stevejuma/ui/ai";
import * as AiChat from "@stevejuma/ui/ai/chat";
import * as ExperimentalAiChat from "@stevejuma/ui/ai/chat/experimental";
```

The stable Chat surface adapts the anatomy and behavior of
[facebook/astryx at `25def2f`](https://github.com/facebook/astryx/tree/25def2f10d28ad135760fc594e817a55a86a1144)
to Svelte 5 and the local design system. The Lab-derived subpath is marked
`@experimental`.

Every stable component page includes an **ASTRYX showcase** and the documented
upstream variants using the pinned example text, token values, tool calls,
statuses, and dimensions. These are reference fixtures for anatomy and
interaction, not copied React/StyleX implementations.

The fixtures intentionally retain the local shadcn theme. ASTRYX brand colors
and Figtree typography are not imported, so geometry can be compared without
changing the package's theme contract. The live comparison record and baseline
boundary are documented in `ASTRYX_AI_VISUAL_PARITY.md`.

| Component                                                             | Role                                        |
| --------------------------------------------------------------------- | ------------------------------------------- |
| [AI Chat Panel](?path=/docs/ai-ai-chat-panel--docs)                   | Full dock + transcript + prompt composition |
| [AI Chat Dock](?path=/docs/ai-ai-chat-dock--docs)                     | Placement / visibility chrome               |
| [AI Chat Transcript](?path=/docs/ai-ai-chat-transcript--docs)         | Message list                                |
| [AI Prompt Input](?path=/docs/ai-ai-prompt-input--docs)               | Composer + send                             |
| [AI Chat Panel Settings](?path=/docs/ai-ai-chat-panel-settings--docs) | Dock / float / collapse controls            |

Hosts compose these prop-driven surfaces with their own forms, routing, and
persistence.
