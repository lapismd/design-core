# Message List

Presentational message container with density context and infinite
scroll support. Provides role="log" with aria-live="polite" for
accessibility. A flex spacer pushes messages to the bottom when the list
isn't full.

Adapted from
[Astryx ChatMessageList](https://astryx.atmeta.com/components/ChatMessageList).

## Examples

Common configurations, variations, and states.

### Density

Side-by-side comparison of compact, balanced, and spacious densities.
Use compact in sidebars or panels, balanced for most full-page chat, and
spacious for long-form reading. Use gap when row spacing needs to differ
from density.
