# Message Bubble

Styled content container for the chat "bubble." Reads sender from parent
ChatMessage context to auto-style the background. Use filled for
standard messages and ghost when content needs alignment without a
visible boundary. Supports name/metadata slots aligned with bubble
padding, and multi-bubble grouping via the group prop for consecutive
messages from the same sender.

Adapted from
[Astryx ChatMessageBubble](https://astryx.atmeta.com/components/ChatMessageBubble).
