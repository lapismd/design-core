# Composer Token

Renders a single token chip outside the contentEditable input. Wraps a
badge config or custom render function in the correct data-astryx-token
span so the token serializes properly and stays visually consistent with
tokens inside the composer.

Adapted from
[Astryx ChatComposerTokenElement](https://astryx.atmeta.com/components/ChatComposerTokenElement).
