# UI-owned shadcn-svelte components

This section renders the editable shadcn-svelte source owned by `@lapismd/design-core`.
It is the visual and behavioural reference for the shared theme tokens and
component contracts that applications consume.

## How to use this catalog

- Read **Shadcn/Guidance** before adding or converting a family (`pnpm ui:add`).
- Check the component story before adding or changing a UI pattern.
- Use the catalog theme switcher to review shared tokens across modes.
- Keep each story beside its source component.
- Import a shared primitive from `@lapismd/design-core/shadcn/<family>`.
- Offline agent summary: `pnpm ui guide shadcn`.

## Component groups

- **Actions:** Button, Toggle, Toggle Group
- **Forms:** Field, Input, Input Group, Label, Textarea, Switch, Select, Command
- **Disclosure:** Accordion, Collapsible, Tabs
- **Overlays:** Alert, Alert Dialog, Dialog, Dropdown Menu, Popover, Tooltip
- **Layout:** Card, Resizable, Scroll Area, Separator, Sidebar
- **Feedback:** Badge, Empty, Skeleton, Spinner

For APIs and upstream examples, see the official
[shadcn-svelte component documentation](https://shadcn-svelte.com/docs/components).
