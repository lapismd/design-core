# MergeWeave Attribution

This package ports and adapts merge editor concepts from MergeWeave / `mismerge`.

The upstream project is licensed under the MIT License.

Copyright (c) Davide Basso

The code in Design Core `src/shared/diff/core/merge` is a framework-free
TypeScript port of `@changeyard/merge`, itself adapted from MergeWeave / `mismerge`.
Svelte components, custom elements, DOM query coupling, and upstream styles are
not included.
