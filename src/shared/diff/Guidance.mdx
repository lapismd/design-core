# Diff guidance

Use `@lapismd/design-core/diff` for change-set file lists, unified or split
file diffs, and one-way or three-way merge editors. Hosts own version-control
commands, file bytes, persistence, and review policy.

Forms still own short field-value review (`UnifiedReviewDiff`). Workspace
Explorer still owns vault create, rename, delete, and auto-reveal. Do not
replace those surfaces with Diff primitives.

Offline agent summary: `pnpm ui guide layers`. Catalog components:
`pnpm ui components --layer diff`.

## Layer boundary

| Need                                          | Package                                         |
| --------------------------------------------- | ----------------------------------------------- |
| Change-set list, folder tree, or package tree | `FileListing` (`@lapismd/design-core/diff`)     |
| Added and removed line counts                 | `FileChangeStats` (`@lapismd/design-core/diff`) |
| Unified or split file comparison              | `FileDiff` (`@lapismd/design-core/diff`)        |
| One-way or three-way merge blocks             | `MergeEditor` (`@lapismd/design-core/diff`)     |
| Short form-field review                       | Forms `UnifiedReviewDiff`                       |
| Vault filesystem chrome                       | Workspace Explorer                              |
| git / jj / PR transport                       | Application host                                |

## Choosing a surface

| Need                                           | Use                     |
| ---------------------------------------------- | ----------------------- |
| Files in one change, with optional `+/−` stats | **FileListing**         |
| Standalone added/removed counts                | **FileChangeStats**     |
| One or many textual file diffs                 | **FileDiff**            |
| Accept left/right/base and resolve conflicts   | **MergeEditor**         |
| A single form value changing in review         | Forms UnifiedReviewDiff |

## Host ownership

Diff components are controlled. The host supplies paths, file texts, selected
path, and merge sides. Internal state may own disclosure such as collapsed
directories or collapsed unchanged context. Do not call git or jj from this
layer.

Line comments, terminal send, and pull-request authors stay in the host. File
Diff exposes `data-diff-line-*`, a `lineAccessory` snippet for row actions, and
a `lineAnnotation` snippet after unified rows so hosts can render inline comment
composers and conversations without moving review policy into Design Core.

## Stories

- **Diff/File Listing** — list, folder tree, and package tree
- **Diff/File Change Stats** — added and removed line counts
- **Diff/File Diff** — unified, split, collapse, multi-file stack, and filled ScrollArea
- **Diff/Merge Editor** — one-way, three-way, editable overlay, MisMerge-style insert/reject, syntax highlighting, filled ScrollArea, and a Changeyard-style settings demo

## Multi-file sections

`FileDiffComposer` retains controlled collapse and repeatable path scrolling.
Use `expandOnHeaderClick` to expand through the full header label area and
presentational `fileHeaderMeta`; keep interactive menus in `fileHeaderTrailing`.
`fileContent` renders host loading, binary or domain previews. Set FileDiff
`sizing="content"` inside a vertically scrolling collection.

| Variable                                  | Default                                                                         | Purpose                                                                                    |
| ----------------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `--ui-diff-file-gap`                      | `0.75rem`                                                                       | Space between file sections.                                                               |
| `--ui-diff-file-section-border`           | `var(--ui-diff-frame-border)`                                                   | Outer section border.                                                                      |
| `--ui-diff-file-section-separator`        | `var(--ui-diff-frame-border)`                                                   | Bottom separator between sections.                                                         |
| `--ui-diff-file-selection-outline-offset` | `1px`                                                                           | Use a negative offset to retain all four outline edges inside a clipping column.           |
| `--ui-diff-file-selection-outline`        | `2px solid var(--ring)`                                                         | Selected section outline; inset edges paint above file content without intercepting input. |
| `--ui-diff-file-content-padding-bottom`   | `0`                                                                             | Space after expanded file content.                                                         |
| `--ui-diff-file-selected-header`          | `var(--muted)`                                                                  | Selected header background.                                                                |
| `--ui-diff-file-header-hover`             | `color-mix(in srgb, var(--foreground) 6%, var(--muted))`                        | Header hover and keyboard focus background.                                                |
| `--ui-diff-file-selected-header-hover`    | `color-mix(in srgb, var(--foreground) 6%, var(--ui-diff-file-selected-header))` | Hover and focus background retaining the selected header tint.                             |
