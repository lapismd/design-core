# SegmentedControl

Exclusive pill control for two or three mutually exclusive values in a form row.

Place inside `FormField align="center" as="div"` when used as a labelled row.

## Guidance

### When to use

- ≤3 mutually exclusive values
- `segmentedField` in StructuredForm configs

### When not to use

- Larger option sets — use shadcn `Select` or `InlineOptionPicker`
- Multi-select — use `ChipAutocomplete`

See also [UI Forms/Guidance](?path=/docs/ui-forms-guidance--docs) and the shared form contract in `spec/src/forms/guidance.md`.

## Style

Colocated CSS: `SegmentedControl.css`. Paint with package tokens from
`@lapismd/design-core/forms/tokens` (defaults in `form.tokens.css`). Stories may
still use host Tailwind for demo layout.

| Token                  | Default                                               |
| ---------------------- | ----------------------------------------------------- |
| `--ui-form-accent`     | `var(--primary)`                                      |
| `--ui-form-border`     | `var(--border)`                                       |
| `--ui-form-foreground` | `var(--foreground)`                                   |
| `--ui-form-muted`      | `var(--muted-foreground)`                             |
| `--ui-form-selection`  | `color-mix(in srgb, var(--primary) 12%, transparent)` |
