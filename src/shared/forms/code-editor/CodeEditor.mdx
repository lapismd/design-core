# CodeEditor

Shared source/code field backed by Mira's language-neutral CodeMirror shell.
Design Core supplies language parsing, diagnostics, and form-token mappings;
Mira owns mounting, lifecycle, base chrome, sizing, and scrolling.

## Guidance

### When to use

- Starter/solution/code fields
- Syntax-aware editing with language + diagnostics

### When not to use

- YAML documents — use `YamlEditor`

See also [UI Forms/Guidance](?path=/docs/ui-forms-guidance--docs) and the shared form contract in `spec/src/forms/guidance.md`.

## Style

Colocated CSS: `CodeEditor.css`. It only maps package tokens from
`@lapismd/design-core/forms/tokens` onto Mira's public
`--mira-code-editor-*` tokens. Editor borders, gutters, content, and scroller
styling stay in Mira. Stories may still use host Tailwind for demo layout.

| Token                       | Default                                              |
| --------------------------- | ---------------------------------------------------- |
| `--ui-form-border`          | `var(--border)`                                      |
| `--ui-form-code-background` | `color-mix(in srgb, var(--muted) 34%, transparent)`  |
| `--ui-form-muted`           | `var(--muted-foreground)`                            |
| `--ui-form-active-line`     | `color-mix(in srgb, var(--primary) 9%, transparent)` |
| `--ui-form-accent`          | `var(--primary)`                                     |
