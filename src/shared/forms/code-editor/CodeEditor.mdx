# CodeEditor

Shared CodeMirror editor for source/code fields. Keep a small outer margin so the editor does not touch panel edges.

## Guidance

### When to use

- Starter/solution/code fields
- Syntax-aware editing with language + diagnostics

### When not to use

- YAML documents — use `YamlEditor`

See also [UI Forms/Guidance](?path=/docs/ui-forms-guidance--docs) and the shared form contract in `FORMS.md`.

## Style

Colocated CSS: `CodeEditor.css`. Paint with package tokens from
`@stevejuma/ui/forms/tokens` (defaults in `form.tokens.css`). Stories may
still use host Tailwind for demo layout.

| Token | Default |
| --- | --- |
| `--ui-form-border` | `var(--border)` |
| `--ui-form-code-background` | `color-mix(in srgb, var(--muted) 34%, transparent)` |
