# ReadOnlyFormRow

Single read-only label/value row for preview surfaces.

## Guidance

### When to use

- Sparse preview rows outside a full `ReadOnlyFormGroup`

### When not to use

- Editable rows — use `FormField`

See also [UI Forms/Guidance](?path=/docs/ui-forms-guidance--docs) and the shared form contract in `FORMS.md`.
