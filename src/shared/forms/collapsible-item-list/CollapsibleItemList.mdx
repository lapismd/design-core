# CollapsibleItemList

Expandable list where the header owns collapse state and an item count pill.

Add action stays in the section footer (below the dotted content outline).

## Guidance

### When to use

- Arrays where the header owns collapse + count
- Simple repeated items that do not need per-entry `FormSectionHeader` titles

### When not to use

- Per-entry editable titles/disclosure — use `FormSectionHeader` + `EntryActions` instead

See also [UI Forms/Guidance](?path=/docs/ui-forms-guidance--docs) and the shared form contract in `FORMS.md`.

<Source language="html" code={"<CollapsibleItemList\n  title=\"Skills\"\n  count={items.length}\n  addLabel=\"skill\"\n  open={open}\n  onToggle={...}\n  onAdd={...}\n>\n  <!-- items -->\n</CollapsibleItemList>"} />

## Style

Colocated CSS: `CollapsibleItemList.css`. Paint with package tokens from
`@stevejuma/ui/forms/tokens` (defaults in `form.tokens.css`). Stories may
still use host Tailwind for demo layout.

| Token | Default |
| --- | --- |
| `--ui-form-accent` | `var(--primary)` |
| `--ui-form-border` | `var(--border)` |
| `--ui-form-foreground` | `var(--foreground)` |
| `--ui-form-muted` | `var(--muted-foreground)` |
| `--ui-form-selection` | `color-mix(in srgb, var(--primary) 12%, transparent)` |
