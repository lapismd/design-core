# Search filter in a form

Composition-only example. `SearchFilterBar` and the filter-query language live
in `@stevejuma/ui/filter`. Forms supply row chrome (`FormField`,
`FormSectionHeader`) and facet pickers (`FilterCommandPicker`).

See [Filter/Guidance](?path=/docs/filter-guidance--docs) and
[Filter/Search Filter Bar](?path=/docs/filter-search-filter-bar--docs).

## Usage

<Source
  language="ts"
  code={`import { SearchFilterBar } from "@stevejuma/ui/filter";
import { FormField, FilterCommandPicker } from "@stevejuma/ui/forms";

<SearchFilterBar inputMode="filter-query" filterSyntax={syntax} value={query} …>
  {#snippet filters()}
    <FormField label="Status" as="div" align="middle">
      <FilterCommandPicker … />
    </FormField>
  {/snippet}
</SearchFilterBar>`}
/>
