# Search Filter in a Form

Composition-only example. `SearchFilterBar` and the filter-query language live
in `@lapismd/design-core/filter`. Forms supply toolbar filter pills via
`FilterCommandPicker` (no `FormField` wrapper — same as Applications board
filters).

## When to use

- Toolbar search above a list or board that also has structured filter controls.

## When not to use

- Do not wrap toolbar filter pills in `FormField`.

## Usage

<Source
  language="ts"
  code={`import { SearchFilterBar } from "@lapismd/design-core/filter";
import { FilterCommandPicker } from "@lapismd/design-core/forms";

<SearchFilterBar inputMode="filter-query" filterSyntax={syntax} value={query} …>
  {#snippet filters()}
    <FilterCommandPicker label="Status" options={statusOptions} value={status} onChange={…} />
  {/snippet}
</SearchFilterBar>`}
/>
