# FilePathInput

Manual path input with an optional native Browse action. The host supplies the
chooser, filters and error reporting; returning `null` cancels. Selection only
updates the controlled string and never imports or reads a file. Pending choices
cannot overwrite newer typed or external values, or update a disabled, read-only
or disposed control. Without `onBrowse`, only manual entry is shown.

The path and Browse button share one focus ring around the complete control.
Tab and Shift+Tab move between them; Enter or Space activates Browse.

<Source code={Basic} language="tsx" />

Settings can declare a string field with `filePicker: { browse, onError }`.
Numeric settings can declare `quantity: { units, preferredUnit, slider }` and
retain their normal canonical number, minimum, maximum and default values.
See UI Forms/Guidance and Workspace/Settings/Unit and File Inputs for composition.
