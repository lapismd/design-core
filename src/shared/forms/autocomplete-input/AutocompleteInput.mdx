# AutocompleteInput

Single-value combobox with filtered suggestions (max 8). Building block under `ChipAutocomplete`.

## Guidance

### When to use

- Inline single-value commit with suggestions
- Custom chip/tag editors

### When not to use

- Multi-value chips — use `ChipAutocomplete`

See also [UI Forms/Guidance](?path=/docs/ui-forms-guidance--docs) and the shared form contract in `FORMS.md`.

## Style

Colocated CSS: `AutocompleteInput.css`. Paint with package tokens from
`@stevejuma/ui/forms/tokens` (defaults in `form.tokens.css`). Stories may
still use host Tailwind for demo layout.
