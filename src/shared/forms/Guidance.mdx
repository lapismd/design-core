# Form guidance

Use `@stevejuma/ui/forms` for structured editing and CV form-row chrome. Use
shadcn for generic controls (`Select`, `Switch`, `Command`, `Input`, …).

## Choose the right layer

1. **StructuredForm** — schema-shaped data with typed field configs from
   `createFormConfig` / `textField` / `segmentedField` / etc.
2. **Composed primitives** — `FormField`, `FormSectionHeader`,
   `CollapsibleItemList`, `InlineOptionPicker` for one-off layouts.
3. **YamlBackedForm** — dual structured + YAML source mode.
4. **shadcn** — Select, Switch, Command/Popover pickers, Toggle Group, Field.

## Layout rules

- Keep labelled fields inside one `cv-structured-form` grid.
- Use `FormField as="div" align="center"` for pill controls, switches, and
  pickers that contain nested interactives.
- Let `FormSectionHeader` own section separators; avoid double borders on
  wrappers.

## Control choice

- `SegmentedControl` for two or three exclusive values in a form row
- `ChipAutocomplete` for multi-value lists (`tagListField` / `chipListField`)
- shadcn `Select` for plain string menus; `InlineOptionPicker` when you need
  swap presentation or option icons
- Prefer app pickers on shadcn `Command` for searchable choices
- `CodeEditor` / `YamlEditor` for source editing
