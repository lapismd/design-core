# QuantityInput

Canonical values are integer strings. Supplied units use positive safe integer numerator/denominator ratios. `onValueChange` receives an exact canonical string, empty for unset values or `NaN` for invalid drafts, matching the source contract. Retain the optional `draft` binding across unmounts to keep invalid input text. Display-unit changes never emit edits. Sliders use at most 1002 discrete values for large ranges and always include the exact current value; typing remains exact. Disabled/read-only, optional values and reset remain host-controlled. Public width/ring tokens are `--ui-quantity-input-width` (18rem) and `--ui-quantity-input-ring` (ring).
