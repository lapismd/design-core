# YamlBackedForm

Dual structured + YAML source mode over the same draft. YAML mode must edit the authoritative serialized document, not a panel copy.

## Guidance

### When to use

- Document editors with a toolbar YAML switch
- AI review diffs on form + YAML counterparts

### When not to use

- YAML-only panels without structured fields — use `YamlEditor` alone

See also [UI Forms/Guidance](?path=/docs/ui-forms-guidance--docs) and the shared form contract in `FORMS.md`.

## Usage

<Source language="html" code={"<YamlBackedForm\n  value={data}\n  config={config}\n  yamlMode={yamlMode}\n  bind:yamlText\n  onChange={...}\n/>"} />

## Style

Colocated CSS: `YamlBackedForm.css`. Paint with package tokens from
`@stevejuma/ui/forms/tokens` (defaults in `form.tokens.css`). Stories may
still use host Tailwind for demo layout.

| Token | Default |
| --- | --- |
| `--ui-form-accent` | `var(--primary)` |
| `--ui-form-border` | `var(--border)` |
| `--ui-form-foreground` | `var(--foreground)` |
| `--ui-form-panel-background` | `var(--ui-form-background)` |
| `--ui-form-primary-foreground` | `var(--primary-foreground)` |
