# FormPlaceholder

Dotted outline box for story/demo bodies so spacing against headers and add actions is visible.

`EntryActions` and `CollapsibleItemList` already outline their content areas — use this for other stubs.

## Guidance

### When to use

- Storybook section bodies
- Tab stubs in composition demos

### When not to use

- Production empty states that need real Empty/CTA chrome

See also [UI Forms/Guidance](?path=/docs/ui-forms-guidance--docs) and the shared form contract in `FORMS.md`.

## Style

Colocated CSS: `FormPlaceholder.css`. Paint with package tokens from
`@lapismd/design-core/forms/tokens` (defaults in `form.tokens.css`). Stories may
still use host Tailwind for demo layout.

| Token              | Default                   |
| ------------------ | ------------------------- |
| `--ui-form-border` | `var(--border)`           |
| `--ui-form-muted`  | `var(--muted-foreground)` |
