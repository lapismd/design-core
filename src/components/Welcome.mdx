# `@stevejuma/ui`

Shared Storybook catalog for shadcn primitives, structured forms, and
app-specific components used by CV Studio and beancount-js-studio.

## Layers

1. **Shadcn** — generic primitives under `src/components/shadcn`
2. **Forms** — config-driven form engine and field controls under `src/components/forms`
3. **App folders** — `src/components/cv` and `src/components/beancount` for domain UI

Import shared primitives from `@stevejuma/ui/shadcn/<family>` and forms from
`@stevejuma/ui/forms`.
